# Game Music Downloads

This is the working shortlist for game music to add to the Navidrome library.

Default rule: prefer official soundtrack albums, not covers, remixes, live
albums, piano collections, or orchestral arrangement albums. Add those variants
later only when the original soundtrack is already in the library.

## Album Selection Notes

### Katana ZERO

Choose:

```text
Katana Zero (Original Soundtrack)
```

Do not start with:

- `Katana Zero (Original Soundtrack) [Live]`
- single-track albums named only `Katana Zero`
- covers or remix albums

QQ Music search found the official OST, but API downloads failed for tested
tracks. If the QQ desktop client can download it manually, decrypt the local
`.mflac` or `.mgg` files with qmdec.

### NieR:Automata

Choose:

```text
NieR:Automata Original Soundtrack
```

Start with:

- `Weight of the World`
- `City Ruins`
- `Amusement Park`
- `A Beautiful Song`
- `Pascal`
- `Copied City`
- `Emil`
- `Vague Hope`
- `Song of the Ancients`
- `The Tower`

Do not start with:

- `Piano Collections`
- `Arranged & Unreleased Tracks`
- `Orchestral Arrangement Album`

Those are good later, but the main original soundtrack should come first.
